2. Cài Đặt Trên Máy Của Con / Em

Thực hiện các bước sau trên máy tính mà bạn muốn quản lý (chỉ cần làm 1 lần duy nhất):


1

Thêm Ngoại Lệ Cho Windows Defender (Tự Động Hoặc Thủ Công)

Do phần mềm chạy ngầm, trình diệt virus Windows Defender có thể quét nhầm và tự xóa file. Bạn có thể thực hiện theo 2 cách cực kỳ dễ dàng:

⚡
Cách 1: Tự Động Hoàn Toàn (Khuyên Dùng)

Khi bạn chạy file Install_Parental_Control.bat (ở Bước 3) dưới quyền Run as Administrator, script sẽ tự động tạo thư mục và tự động thêm vào Ngoại Lệ (Exclusion) của Windows Defender cho bạn mà không cần làm gì thêm!

Cách 2: Tự thêm thủ công (Nếu muốn chuẩn bị trước):

  1. Mở ứng dụng Windows Security từ menu Start.
  2. Chọn mục Virus & threat protection (Bảo vệ khỏi mối đe dọa).
  3. Ở phần Virus & threat protection settings, bấm vào Manage settings.
  4. Cuộn xuống mục Exclusions, bấm Add or remove exclusions.
  5. Bấm nút + Add an exclusion → Chọn Folder.
  6. Dán hoặc chọn đường dẫn thư mục cài đặt chính thức:
    C:\ProgramData\ParentalControl
💡
Giải thích lỗi "Không tìm thấy thư mục":

Nếu bạn thêm thủ công trước khi cài đặt mà Windows báo không tìm thấy thư mục C:\ProgramData\ParentalControl, đó là vì thư mục này chưa được tạo. Bạn chỉ cần chạy file Install_Parental_Control.bat (Bước 3), thư mục sẽ tự động được tạo và cấu hình ngoại lệ ngay lập tức!

2

Chép File Và Giải Nén Bộ Cài Đặt

  1. Chép file bộ cài đặt ParentalControl_Setup.zip vào máy tính của con.
  2. Nhấn chuột phải vào file ZIP → Chọn Extract All... (Giải nén tất cả) để xả nén file ra thư mục.
3

Kích Hoạt Cài Đặt Tự Động (Run as Administrator)

  1. Mở thư mục vừa giải nén, tìm file có tên: Install_Parental_Control.bat
  2. Nhấn chuột phải vào file đó → Chọn dòng Run as administrator (Chạy dưới quyền quản trị viên).
  3. Nếu màn hình hiện hộp thoại hỏi "Do you want to allow this app...", bấm Yes.
  4. Một cửa sổ đen sẽ hiện lên tự động cài đặt trong 5-10 giây và báo "CAI DAT HOAN TAT THANH CONG!".
🎉
Hoàn tất cài đặt!

Phần mềm đã bắt đầu chạy ngầm hoàn toàn vĩnh viễn và tự động khởi động cùng Windows. Bạn có thể xóa file zip cài đặt ban đầu đi.

3. Hướng Dẫn Sử Dụng Trang Web Quản Lý

Bạn có thể dùng điện thoại hoặc máy tính cá nhân mở đường dẫn Web Management Dashboard để theo dõi và điều khiển từ xa bất kỳ lúc nào.


📸

1. Xem Báo Cáo & Ảnh Màn Hình

Vào tab Lịch Sử & Báo Cáo để xem các ảnh chụp màn hình máy tính con em theo mốc thời gian, xem danh sách các ứng dụng/game đang mở và thời gian đã sử dụng trong ngày.

⏱️

2. Cài Đặt Giới Hạn Thời Gian Sử Dụng

Vào tab Cấu Hình Thời Gian:

  • Theo thời lượng: Nhập số giờ tối đa/ngày (Ví dụ: 2 giờ/ngày). Khi hết 2 giờ sử dụng, máy sẽ tự động khóa màn hình.
  • Theo khung giờ: Chọn giờ bắt đầu và giờ kết thúc (Ví dụ: Chỉ cho dùng từ 19:00 đến 21:00). Ngoài giờ này máy sẽ bị khóa.
🚫

3. Thêm Quy Tắc Chặn Ứng Dụng & Trang Web

Vào tab Quy Tắc Chặn:

  • Chặn Game/App: Nhập tên file (Ví dụ: garena.exe, roblox.exe) → Chọn Cấm hoàn toàn.
  • Chặn Website: Nhập tên trang web (Ví dụ: facebook.com, youtube.com) → Chọn Cấm hoàn toàn. Khi con truy cập web này, trình duyệt sẽ tự động bị đóng ngay.

4. Các Câu Hỏi Thường Gặp (FAQ)

❓ Làm sao để biết phần mềm trên máy con có đang chạy hay không?

Trên trang Web Quản lý, góc trên màn hình sẽ có đèn trạng thái thiết bị. Nếu hiển thị 🟢 Online nghĩa là máy tính đang bật và phần mềm đang hoạt động bình thường.

❓ Nếu máy tính con bị mất mạng Internet thì phần mềm có khóa máy được không?

CÓ, HOÀN TOÀN ĐƯỢC. Hệ thống được thiết kế theo công nghệ Local-First. Mọi dữ liệu về giờ giấc và quy tắc chặn được lưu trực tiếp trên máy con. Ngay cả khi con rút dây mạng hoặc tắt Wi-Fi, máy vẫn tự động tính giờ và khóa màn hình khi hết giờ.

❓ Nếu con bấm Ctrl + Alt + Delete hoặc mở Task Manager thì có tắt được phần mềm không?

KHÔNG THỂ. Khi màn hình bị khóa, phần mềm đã tự động vô hiệu hóa Task Manager và các phím tắt hệ thống. Đồng thời tiến trình chạy dưới quyền tối cao của Windows (SYSTEM) nên không thể bị tắt bằng tay.

❓ Mật khẩu mở khóa trực tiếp trên màn hình máy con là gì?

Khi máy bị khóa, nếu phụ huynh muốn mở khóa trực tiếp tại máy mà không cần mở Web, chỉ cần nhập mật khẩu quản lý ban đầu (Đã được thiết lập mặc định trong cấu hình hệ thống) vào ô nhập mật khẩu trên màn hình khóa.
