2. QUY TẮC MỞ RỘNG GIAO DIỆN & TÍNH NĂNG MỚI (FUTURE EXTENSION RULE)
------------------------------------------------------------------------------
KHI THÊM BẤT KỲ THẺ (CARD), NÚT (BUTTON), FORM HOẶC BẢNG NÀO VÀO ỨNG DỤNG:
1. Import hàm `getThemeStyles`:
   import { getThemeStyles } from "../lib/theme";
2. Lấy đối tượng styles trong component:
   const styles = getThemeStyles(theme);
3. Áp dụng chuẩn các class token đã định nghĩa:
   <div className={`p-5 rounded-xl border ${styles.card}`}>
     <h3 className={`text-sm font-bold ${styles.textBold}`}>Tiêu đề</h3>
     <p className={`text-xs ${styles.textMuted}`}>Mô tả</p>
     <button className={`px-4 py-2 ${styles.buttonPrimary}`}>Hành động</button>
   </div>

TUYỆT ĐỐI KHÔNG TỰ VIẾT MÃ MÀU AD-HOC (NHƯ bg-gray-100, text-zinc-500) TRONG CÁC COMPONENT.
